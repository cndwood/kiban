# Kiban — Engineering-Handbuch

Ein deutschsprachiger, mehrmonatiger NO-AI-CODING-Lehrgang zum eigenständigen Bau einer Multiplayer-Plattform für traditionelle asiatische Brettspiele. Xiangqi bildet das MVP; Junqi, Shogi und Go bestimmen die langfristigen Modulgrenzen.

**Dieses Repository enthält ausschließlich Planung und Lernmaterial. Es gibt keine Anwendung und keine initialisierten Rust- oder Godot-Projekte.** Alle Implementierungsaufgaben sind vom Lernenden selbst auszuführen.

Start: [Lernleitfaden](docs/LEARNING_GUIDE.md), dann [Kapitel 01](docs/chapters/01-workspace.md). Navigation: [Index](docs/INDEX.md), [Roadmap](docs/ROADMAP.md), [Fortschritt](docs/checklists/project-progress.md).

Das MVP umfasst Gäste, öffentliche/private Partien, serverseitige Xiangqi-Regeln, Uhren, Wiederverbindung, persistente Historie und Godot-Oberfläche. Accounts und Ratings folgen nach dem produktiven MVP. Die Dokumentationsfertigstellung bedeutet nicht, dass eine Implementierungsaufgabe erledigt ist.

Verbindliche Entscheidungen stehen in [ADRs](docs/decisions/README.md), Verträge unter [Protokoll](docs/protocol/overview.md). Quellenprüfung und Grenzen stehen im [Quellenregister](docs/SOURCES.md).
